      Neural lab

      Watch a neural network learn

      ● class A● class BTap the plot to add points. Shift-click adds the other class.
      Press ▶ Train to start. The network begins with random weights, so its first guess is a random split.
      What is this, and what is it doing?

      What it is: a tiny neural network (a multi-layer perceptron) training live in your browser. It is the same thing you build in Karpathy's micrograd: no AI tokens are used.

      The task: each dot is a 2-D point with a label, red (A) or blue (B). The network gets the point's x and y and must output the probability it is blue.

      What each part shows
      • Background colour: the network's current guess for every spot. Blue = it thinks B, red = it thinks A, faint = unsure. The edge between them is the decision boundary.
      • Loss: how wrong it is (binary cross-entropy). Lower is better.
      • Accuracy: the % of dots on the correct side.
      • Loss curve: loss over time. It should slope down.
      • Network diagram: circles are neurons (2 inputs on the left, 1 output on the right); lines are weights: thicker = stronger, blue = positive, red = negative.
      • Epoch: one full pass over all the dots.
      What happens on every step
      1. Forward pass: each point flows through the layers (weighted sum + activation) to a prediction.
      2. Loss: compare predictions with the true labels.
      3. Backpropagation: the chain rule computes how much each weight caused the error.
      4. Gradient descent: nudge every weight a little (by the learning rate) to reduce the loss.
      Experiments to try
      • Spiral with 1 layer × 2 neurons: it fails (too small). Then 2 × 8: it learns. Depth and width add power.
      • Learning rate 1.0: the loss jumps around. 0.01: it crawls. Step size matters.
      • tanh vs ReLU: ReLU gives sharp, angular boundaries; tanh gives smooth ones.
      • Noise 0.4: the classes overlap, so 100% is impossible; a smooth boundary is better than one that chases every dot (overfitting).

      Attention visualiser

      See what each word looks at

      What is this?

      Attention is how a transformer lets each word gather information from other words. Each row of the grid is one word asking "who should I look at?"; the brightness of each cell is how much attention it pays to that column's word. Every row adds up to 100% (that's the softmax).

      Real models have dozens of heads per layer, each learning a different pattern. These 4 heads use hand-set rules that copy patterns researchers have actually found in trained GPTs, so you can see the mechanics without running a model (no tokens used).

      Causal mask: in GPT, a word may only look at earlier words, so the top-right triangle is blank. Turn it off to see BERT-style attention.

      In Karpathy's "Let's build GPT", this grid is wei = softmax(q @ k.T / sqrt(d)) with the mask applied.
