# Learning Galaxy

A study HUD with an AI assistant, as an installable app (PWA): plan your days, build YouTube courses, map your
skills, follow AI news and trending repos, practise with flashcards, quizzes and a neural-network lab, and talk to
**Jarvis**, who can run the whole app for you and even ask Claude to **build new features into it**.

- **Live:** https://learning-galaxy-arpit.netlify.app
- **Setup:** [docs/SETUP.md](docs/SETUP.md)
- **For contributors / Claude:** [CLAUDE.md](CLAUDE.md)

Data stays on your device (IndexedDB) and optionally syncs through your own Supabase project.
AI runs on your own key. Feature requests become GitHub issues that Claude Code builds, tests and ships.

The previous Gist-based version is kept at tag [`v1-gist`](../../tree/v1-gist).
